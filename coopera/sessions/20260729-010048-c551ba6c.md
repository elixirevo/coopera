# Session digest — c551ba6c-49e0-42df-ba2a-c2717596da2f (claude-code)
author: Elixir · 2026-07-29T01:00:48.103748Z
intent: Finalize the architecture and implementation strategy for coopera, a git-backed team context harness enabling all team members' AI agents to develop with shared project understanding
decisions:
- Each AI tool (Claude Code, Codex, Antigravity) performs its own session distillation using existing infrastructure (claude -p headless, codex exec, Antigravity's next-SessionStart), not centralized API — distillation cost attributed to each user's subscription, zero API-key burden.
- Wiki changes from distillation stage in the working branch and ride with the code PR, unified review — not separate wiki PRs — so knowledge promotion is atomic with code promotion and review fatigue doesn't kill wiki.
- Presence refs are per-session, not per-user, to support parallel worktree workflows where one developer runs multiple concurrent AI agents simultaneously.
- SessionStart must display '1-line summary: Team context injected — N active · M decisions · K stale excluded' — invisible injection kills adoption (Cursor auto-memory case study).
- Presence is strictly coordination-only: no time tracking, activity metrics, or performance inference — opt-out guaranteed, anti-surveillance principle — to preserve developer trust.
learnings:
- MCP resource subscriptions and push notifications don't propagate to LLM in Claude Code/Codex (verified July 2026); must pull at hook-time (SessionStart, UserPromptSubmit) instead.
- Git custom refs with per-session scope (`refs/coopera/presence/<user>/<session>`) eliminate merge conflicts entirely in multi-developer parallel workflows.
- No existing harness combines all four: git-backed persistence + automatic distillation + cross-developer injection + zero servers; investigated 20+ projects, all pick a subset.
- Invisible automatic context injection fails adoption (Cursor auto-Memories was killed and reverted to explicit AGENTS.md rules); transparency is prerequisite for user trust.
