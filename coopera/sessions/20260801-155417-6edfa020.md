intent: Complete M1/M2 milestones, self-host coopera on its own repo, ship multi-platform binary releases with a rolling CI/CD pipeline, and fix portability issues (machine-independent hooks, visible wiki directory)
decisions:
- Wiki lives in visible coopera/ directory (not .wiki or .coopera/wiki): ripgrep — the engine behind most AI agent search tools — skips dotdirs by default, so a hidden wiki is invisible to organic agent exploration and to teammates in read-only mode. Visibility is load-bearing for the product's core value.
- Committed hook commands use ${COOPERA_BIN:-coopera} (PATH lookup), never an absolute path: absolute paths from the installer's machine break hooks for every other teammate; teammates without the binary get a silent empty-JSON pass-through (read-only mode) instead of errors; local builds override via COOPERA_BIN in their shell profile without touching committed config.
- Rolling 'latest' release fires on every push to main (not only on version tags): test gate runs first; all four platform binaries (macOS arm64/intel, Linux x86_64, Windows x86_64 MSVC) are rebuilt and the latest release is updated atomically via API to avoid re-triggering the workflow.
learnings:
- ripgrep (used by Claude Code Grep and most AI agent file-search) skips hidden directories by default — any knowledge store placed in a dotdir is effectively invisible to agent exploration without --hidden.
- CI runners have no global git identity; git commit-tree (used internally for presence ref publishing) requires user.name/email — fix with per-command -c flags, not by mutating global config.
- Antigravity-only machines have no hook to refresh .coopera/cache/presence.md; AGENTS.md instructs agents to read it, but the file may be absent or stale on those machines — identified gap, manual coopera activity command is the planned mitigation.
- The --retro distillation path qualifies sessions only when transcript >= 16 KB AND <= 14 days old AND no existing digest; sessions below the threshold are intentionally skipped as having insufficient distillable content.
